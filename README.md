## Who I work with

- **Established businesses** whose operations still run on spreadsheets and an
  ERP nobody maintains. I map what you actually run, then rebuild it on
  something maintainable — carrying the data across without pausing the business.
- **Founders** who need an internal tool built properly, once, without having to
  justify a hire for it.

## How an engagement runs

1. **Paid Discovery**, one week. You get a plain-English system map and a build
   specification with a fixed price — yours to keep whether you build with me or
   take it elsewhere.
2. **Fixed-price build**, demoed at every milestone. The price moves only if you
   change scope in writing. Data migration is part of the build, not an
   afterthought.
3. **30–60 days of support** after go-live, included. Source code, credentials
   and documentation hand over at the end.
4. **Retainer**, optional and never a condition.

No open-ended hourly billing.
